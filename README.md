# Portfolio

This is a personal portfolio project built with Angular. It showcases my skills, experience, and projects.

## Features

*   **Home:** A landing page.
*   **About:** Information about me.
*   **Jobs:** My work experience.
*   **Skills:** My technical skills.
*   **Education:** My educational background.
*   **Works:** A gallery of my projects.
*   **Contact:** A form to get in touch.
*   **Authentication:** Login and registration functionality.

## Technologies Used

*   [Angular](https://angular.io/)
*   [Firebase](https://firebase.google.com/) for backend and authentication.
*   [Bootstrap](https://getbootstrap.com/) for styling.
*   [ng-circle-progress](https://www.npmjs.com/package/ng-circle-progress) for circular progress bars.
*   [ngx-toastr](https://www.npmjs.com/package/ngx-toastr) for notifications.

## Getting Started

### Prerequisites

*   [Node.js](https://nodejs.org/)
*   [Angular CLI](https://cli.angular.io/)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/portfolio.git
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```

### Running the application

1.  Run the development server:
    ```bash
    ng serve
    ```
2.  Open your browser and navigate to `http://localhost:4200/`.

## Available Scripts

*   `ng serve`: Starts the development server.
*   `ng build`: Builds the project.
*   `ng test`: Runs the unit tests.
*   `ng lint`: Lints the project.
